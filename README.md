# Genogram Maker (หน้าเว็บ static, ข้อมูลอยู่ในเครื่องผู้ใช้)

เปิด `index.html` ในเบราว์เซอร์ได้เลย (ไม่ต้องมีเซิร์ฟเวอร์) · ไม่มีการเรียกเครือข่ายภายนอก · ฟอนต์ Sarabun (OFL) ฝังใน `fonts.js`

## ไฟล์
- `index.html` หน้าเว็บ + CSS · `engine.js` วาดผัง (ฟังก์ชันล้วน) · `store.js` ที่เก็บข้อมูล · `app.js` UI/ส่งออก/สำรอง · `fonts.js` ฟอนต์

## ข้อมูลไม่หายได้อย่างไร
1. IndexedDB (หลัก) บันทึกอัตโนมัติ 0.4 วินาทีหลังแก้
2. สำเนา localStorage (เขียนซ้ำทุก ~1.2 วินาทีและตอนปิดแท็บ) — ถ้าอย่างใดอย่างหนึ่งหาย อีกชั้นกู้ให้ตอนเปิด
3. ประวัติย้อนหลังอัตโนมัติ ผังละ 40 จุด (กู้ได้ที่ "สำรอง / กู้คืน")
4. ถังขยะ (ลบผังแล้วกู้ได้)
5. ไฟล์สำรอง: ดาวน์โหลด .json หรือ "เชื่อมไฟล์อัตโนมัติ" (Chrome/Edge) — **ชั้นเดียวที่รอดเมื่อล้างข้อมูลเบราว์เซอร์/เปลี่ยนเครื่อง**
- เตือนบนหน้าจอเมื่อแก้งานเกิน 15 นาทีโดยยังไม่สำรองไฟล์

หมายเหตุ: `file://` กับ URL ที่โฮสต์จริง เป็นคนละที่เก็บ — ย้ายข้อมูลด้วยไฟล์สำรอง

## ห้ามนำข้อมูลจริงขึ้น repo สาธารณะ
ผังมีชื่อชาวบ้านได้ ใช้ "ตัวย่อ" เมื่อส่งออกลงรายงาน

## ตามตารางสัญลักษณ์ของคู่มือปี 69 (หน้า 63)
- ครบ 22 แบบ (บุคคล 11 + เส้นความสัมพันธ์ 11) · ตัวเลือก "ครบตามตารางของคู่มือ" ในหน้าส่งออกจะแสดงตารางเต็มใต้ผัง
- ส่วนเพิ่มที่เล่มรายงานปี 68 เขต 3/7/9 ใช้: ลูกศรผู้ให้ข้อมูล, ระบายเหลือง "ผู้ให้ข้อมูลหลัก", ตัวอักษรแยกสีตามชนิดข้อมูล, กรอบบ้านเดียวกันเป็นกล่องมุมมน — เปิดปิดได้ที่แผง "ข้อมูลผังนี้"

## ข้อความ
- ลากข้อความใต้สัญลักษณ์ไปวางที่ใดก็ได้ (มีเส้นประโยงกลับ) · ปรับขนาด/สี/ซ่อนทีละคน
- กล่องข้อความอิสระ (＋ ข้อความ): ลากย้าย ปรับขนาด สี ตัวหนา จัดชิด · ดับเบิลคลิกเพื่อแก้
- ช่องข้อมูลรายคน: ระดับการศึกษา อาชีพ บทบาทในชุมชน ย้ายถิ่น พฤติกรรมเสี่ยง

## ส่งออก "แบบเล่มรายงาน" (ลงกระดาษ A4/A3 1–2 หน้า)
- เลือก "แบบเล่มรายงาน" ในหน้าส่งออก: ขยายข้อความให้ใหญ่กว่าสัญลักษณ์ พับแถวให้เต็มหน้า (เลือกจำนวนแถว อัตโนมัติ/1/2/3) ย่อเฉพาะป้ายที่ทับกัน ซ่อนบรรทัดรอง (ตัวเลือก) และขยายคำอธิบายสัญลักษณ์ตามที่ว่าง · ส่งออกได้เป็น PDF / PNG 300 dpi / SVG / .pptx (Canva)
- **ตัดเฉพาะส่วนที่เลือก**: ลากกรอบเลือกคน (ปุ่ม "เลือกหลายคน") แล้วติ๊ก "ตัดเอาเฉพาะส่วนที่เลือก" ในหน้าส่งออก (ใช้ได้กับโหมดหน้าเดียว / แถวเดียวยาว / แบบเล่มรายงาน)
- **ตั้งจุดตัดแถวเอง**: ปุ่ม "✂ ตั้งจุดตัดแถว" แล้วคลิกตำแหน่งบนผังตรงไหนก็ได้ที่จะตัด (คลิกใกล้เส้นเดิมเพื่อลบ, ปุ่ม "ล้างจุดตัด" ล้างทั้งหมด) หรือใช้ปุ่ม "เริ่มแถวใหม่ที่คนนี้" ในแผงคนที่เลือก · ส่งออกแบบเล่มรายงานจะตัดตามจุดที่ตั้ง (ป้ายข้อความที่คร่อมเส้นตัดจะถูกตัดครึ่ง — วางเส้นในช่องว่างระหว่างครอบครัว)
- **ตัดภาพส่งออกแบบ Snipping Tool**: ปุ่ม "▭ ตัดภาพส่งออก" แล้วลากกรอบบนผัง (กรอบสีน้ำเงิน, "ล้างพื้นที่" เพื่อลบ, Esc เพื่อปิดโหมด) · หน้าส่งออกจะส่งออกเฉพาะพื้นที่นั้น (โหมดหน้าเดียว/แถวเดียวยาว ตัดตามกรอบเป๊ะ, โหมดแบบเล่มรายงานใช้คนที่อยู่ในกรอบ)
- ตัดตามสายแล้วเลขรุ่น I–V จะไม่แสดง · ตัวอักษรบนกระดาษดูได้ที่ข้อความสรุปในหน้าส่งออก
- แก้บั๊ก: ส่งออก .pptx (Canva) โหมดพับแถว/ชุดลงเล่ม เคยใส่ข้อความซ้ำนอกสไลด์

## แก้พ่อแม่ที่โยงผิด (ไม่ต้องลบคน)
- เลือกคน → แผง "พ่อแม่ของคนนี้" บอกว่าเป็นลูกของใคร · **เปลี่ยนพ่อแม่…** แล้วคลิก "เส้นคู่ชีวิต" ของพ่อแม่ใหม่บนผัง (หรือคลิกตัวพ่อ/แม่ที่มีคู่เดียว; คนที่ยังไม่มีคู่จะได้เส้นพ่อ/แม่คนเดียว) · **ตัดออกจากพ่อแม่** = ไม่ให้เป็นลูกของใคร (ตัวคนและข้อมูลอยู่ครบ)
- เลือกเส้นคู่ชีวิต → แผง "ลูกของคู่นี้" เรียงซ้าย→ขวา มีปุ่ม "เปลี่ยน…" / "ตัดออก" ต่อคน
- ปฏิเสธเมื่อ: ตั้งตัวเองเป็นพ่อแม่ตัวเอง, คู่ที่เลือกเป็นลูกหลานของคนนี้ (วนรอบ) · ถ้าคนนั้นมีเส้นแฝดจะยกเลิกเส้นแฝดให้ · ย้ายขึ้นแถวเดียวกับพี่น้องใหม่ (เฉพาะแนวตั้ง) · กด "ย้อนกลับ" ได้ทุกครั้ง · Esc ยกเลิกโหมดเลือก

## ปรับเส้นความสัมพันธ์ (สนิทกัน, ทะเลาะ, ห่างเหิน ฯลฯ)
- คลิกเส้น → ลากวงกลมสีส้มกลางเส้นเพื่อดัดโค้ง · **ดับเบิลคลิก (หรือแตะสองครั้ง) บนเส้น = เพิ่มจุดเลี้ยว** ลากเส้นให้อ้อมคนที่ขวางได้หลายจุด · ดับเบิลคลิกที่จุดเพื่อลบ · ปุ่ม "＋ เพิ่มจุดเลี้ยว" / "ลบจุดเลี้ยวทั้งหมด" ในแผงขวา (จุดเลี้ยวตามคนเวลาย้ายคน)
- **ด้านที่เส้นออก/เข้าตัวคน**: เลือก อัตโนมัติ / บน / ล่าง / ซ้าย / ขวา แยกแต่ละปลาย เพื่อไม่ให้เส้นพาดทับชื่อหรือโรคที่เขียนใต้สัญลักษณ์
- **ป้ายบนเส้น** (เช่น ห่างเหินตั้งแต่ปี 2560): พิมพ์ในแผงขวา แล้วลากป้ายไปวางตรงไหนก็ได้ ("คืนตำแหน่งป้าย" ได้) · ติดไปกับการส่งออก
- **เลี่ยงคนอัตโนมัติ**: ปุ่มในแผงเส้น (ล้างที่ปรับเองแล้วเลือกความโค้งที่ไม่ชนคน) และเมนู "⚙ จัดวาง → จัดเส้นความสัมพันธ์ให้เลี่ยงคน" ทำทุกเส้นที่ยังไม่ได้ปรับเอง (เส้นที่มีจุดเลี้ยว/ตั้งด้านไว้ไม่ถูกแตะ)
- แผงเตือนชื่อคนที่เส้นพาดผ่านตัว/ชื่อ · "สลับทิศลูกศร" ไม่ทำให้รูปเส้นเปลี่ยนแล้ว

## วาดวงบ้านเอง (เหมือนเขียนใน GoodNotes)
- กดปุ่ม **✎ วาดวงบ้านเอง** (เปิดอยู่จนกว่าจะกดอีกครั้งหรือกด Esc) แล้วลากปากกา/นิ้ว/เมาส์เป็นวงรอบคนที่อยู่ด้วยกัน ลากต่อได้หลายวง (เริ่มลากบนตัวคนก็ได้ จะไม่ไปลากย้ายคน)
- ปล่อยเมาส์แล้วแอปปรับเส้นให้เนียน นับคนที่อยู่ในวงให้ และ **วงตามคนเวลาย้ายคน** (ติ๊ก "ตรึงตำแหน่ง" ถ้าไม่ต้องการ) · คนที่ถูกลบออกจากผัง วงไม่กระโดด
- **วาดวงข้ามระยะไกล (คนอยู่ไกลกัน)**: (1) ลากไปชิดขอบพื้นที่วาด ผังจะเลื่อนตามเอง ไม่ต้องยกปากกา (ยิ่งชิด/เลยขอบ ยิ่งเลื่อนเร็ว) · (2) ติ๊ก **"ยกปากกาได้"** ข้างปุ่มวาดวง: ยกปากกา/เมาส์ได้ เส้นที่ลากไว้ค้างอยู่ เลื่อนหรือซูมผังแล้วลากต่อ หรือแตะ/คลิกวางจุดเพิ่มได้ จนกด **"ปิดวง"** (หรือ Enter) · "ย้อนเส้นล่าสุด" (Backspace) · "ยกเลิก" (Esc) · เส้นประสีส้มจาง = ช่วงที่ยกปากกาข้าม · หมุนล้อเมาส์ซูมกลางเส้นได้ตลอด
- **ตัวช่วยให้วงสวย**: ช่อง "วงที่วาด: …" ข้างปุ่มเลือกรูปหลังวาด (ปรับให้สวยอัตโนมัติ = ถ้าลากใกล้เคียงวงรีจะเป็นวงรีเรียบร้อย ไม่งั้นเรียบแบบโค้ง / เรียบ / วงรี / กล่องมุมมน / ตามที่ลากจริง) · **ค้างปากกาไว้ ~0.6 วินาทีตอนท้าย** = กลายเป็นวงรีเรียบร้อย · ปลายเส้นที่ลากเลยจุดเริ่มจะถูกตัดทิ้งเอง · แผงขวามีปุ่ม "เรียบ / วงรี / กล่องมุมมน / ตามที่ลากจริง" เปลี่ยนรูปทีหลังได้จากเส้นเดิม, "ห่อให้พอดีสมาชิก", "ขยายวงให้พ้นตัวคน" และบอกชื่อคนที่เส้นตัดผ่านตัว/ชื่อ
- คลิกเส้นวงเพื่อเลือก: ใส่ป้าย (เช่น บ้านเลขที่ 23/3), เปลี่ยนสี/ความหนา/เส้นประ, ใช้เส้นตามที่ลากจริง, "ทำให้เป็นวงรีเรียบร้อย", "นับคนในวงใหม่", ลากเส้นเพื่อย้ายทั้งวง, ลบด้วยปุ่มหรือ Delete · ย้อนกลับได้ทุกขั้น
- ติดไปกับการส่งออกทุกแบบ (PDF/PNG/SVG/.pptx) และขึ้นในคำอธิบายสัญลักษณ์ "สมาชิกที่อยู่ด้วยกัน" · ข้อควรระวัง: ส่งออกแบบเล่มรายงานที่พับแถว ถ้าเส้นตัดแถวผ่ากลางวง วงจะถูกตัดครึ่ง — วางเส้นตัดไว้ระหว่างบ้าน
