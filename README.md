# Genogram Maker (หน้าเว็บ static, ข้อมูลอยู่ในเครื่องผู้ใช้)

เปิด `index.html` ในเบราว์เซอร์ได้เลย (ไม่ต้องมีเซิร์ฟเวอร์) · ไม่มีการเรียกเครือข่ายภายนอก · ฟอนต์ Sarabun (OFL) ฝังใน `fonts.js`

## ไฟล์
- `index.html` หน้าเว็บ + CSS · `engine.js` วาดผัง (ฟังก์ชันล้วน) · `store.js` ที่เก็บข้อมูล · `app.js` UI/ส่งออก/สำรอง · `fonts.js` ฟอนต์

## ข้อมูลไม่หายได้อย่างไร
1. IndexedDB (หลัก) บันทึกอัตโนมัติ 0.4 วินาทีหลังแก้
2. สำเนา localStorage (เขียนซ้ำทุก ~1.2 วินาทีและตอนปิดแท็บ) — ถ้าอย่างใดอย่างหนึ่งหาย อีกชั้นกู้ให้ตอนเปิด
3. ประวัติย้อนหลังอัตโนมัติ ผังละ 40 จุด (กู้ได้ที่ "สำรอง / กู้คืน")
4. ถังขยะ (ลบผังแล้วกู้ได้)
5. ไฟล์สำรอง: ดาวน์โหลด .json หรือ "เชื่อมไฟล์อัตโนมัติ" (Chrome/Edge) — **ชั้นเดียวที่รอดเมื่อล้างข้อมูลเบราว์เซอร์/เปลี่ยนเครื่อง**
- เตือนบนหน้าจอเมื่อแก้งานเกิน 15 นาทีโดยยังไม่สำรองไฟล์

หมายเหตุ: `file://` กับ URL ที่โฮสต์จริง เป็นคนละที่เก็บ — ย้ายข้อมูลด้วยไฟล์สำรอง
